# Five-minute demo script

1. Open the dashboard and point out the signal snapshot and evidence-led positioning.
2. Click **New interview**, enter a candidate and role, then step through the three seeded questions.
3. Use the optional transcript field to demonstrate deterministic local mode, or record from a browser microphone.
4. Complete the session and open the candidate row to review score, recommendation, keywords, confidence, and rationale.
5. Download the ReportLab PDF and show the question breakdown and safety disclaimer.
6. Open Rubric Studio to show the YAML-backed criteria and question bank.

The demo does not require an API key. For live provider testing, configure `AI_PROVIDER=openai` and the key only in the backend environment.
